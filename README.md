# himanshubisoyi.com

Source code of my portfolio and freelance website: **[himanshubisoyi.com](https://himanshubisoyi.com)**

I'm Himanshu Bisoyi, a Senior Software Engineer at The Akshaya Patra Foundation and a freelance website developer in Hyderabad, India. This site presents my services, prices, client projects and resume.

## Highlights

- **Fast static site:** plain HTML, CSS and JavaScript (jQuery), with no build step
- **Lighthouse:** 100 for SEO, Accessibility and Best Practices on every page; Performance 89–100
- **Images:** WebP in two sizes with `srcset`, plus `width` and `height` on every image to avoid layout shift
- **Fonts:** self-hosted Jost and Montserrat, with the main font preloaded
- **SEO:** a unique title, description and canonical URL on each page, Open Graph tags, an XML sitemap and IndexNow
- **Structured data (JSON-LD):** Person, ProfessionalService, Service, FAQPage, Article, ProfilePage, ContactPage and BreadcrumbList
- **Landing pages:** separate pages for website development in Hyderabad, e-commerce development, and website cost in India
- **Contact form:** sends enquiries through Web3Forms, with no server code
- **Hosting:** Cloudflare Pages, with caching and security headers set in `_headers` and redirects in `_redirects`
- **Extras:** a print-friendly resume page, a real 404 page and `llms.txt` for AI search tools

## Run locally

It is a static site, so any local web server works, for example:

```bash
npx serve .
```

Then open http://localhost:3000.
