This project involved designing and building a responsive and professional website for Scitemp Cooling Equipment LLC, a company focused on laboratory and cooling equipment solutions. As a Frontend / Full Stack Developer, I developed the user interface using HTML, CSS, JavaScript and integrated backend functionality using PHP.

Key Features:

  • Responsive design that adapts across desktop, tablet, and mobile devices.
  • Equipment catalog / product pages with filtering, sorting and detailed views.
  • Interactive UI/UX elements (hover effects, transitions) to improve user engagement.
  • Contact / enquiry form with backend (PHP) support to process submissions.
  • Dynamic data rendering with JavaScript & backend integration.

Technologies Used:

HTML5, CSS3, JavaScript, PHP

Challenges Solved:

Managing performance for heavy product pages and images, ensuring fast load times. Ensuring cross-browser compatibility and responsiveness across varied devices. Handling form submissions securely, validating input on both client & server side. Integrating dynamic content with minimal delay using JS + PHP.
